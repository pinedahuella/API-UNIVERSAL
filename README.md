# API-UNIVERSAL

Demostracion de API UNIVERSAL. Pagina estatica: HTML, CSS y JavaScript.

La persona se registra, elige sus intereses y la pagina se arma distinta para
cada quien: color, orden del contenido y publicaciones. Adentro, cada me gusta,
guardado o video que abre vuelve a cambiar su pantalla, y cuando dos intereses
coinciden aparece contenido combinado.

Funciona en telefono y en computadora. No hay servidor: todo corre en el navegador.

Abrir: https://pinedahuella.github.io/API-UNIVERSAL/
