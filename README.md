# API-UNIVERSAL

Demostracion de API UNIVERSAL. Pagina estatica: HTML, CSS y JavaScript.

La persona se registra, elige sus intereses y la pagina se arma distinta para
cada quien. Adentro, cada like o video que abre vuelve a cambiar su pantalla.

El panel de la derecha muestra la respuesta que la conexion le devuelve al
sistema para armar esa pantalla.

Abrir: https://pinedahuella.github.io/API-UNIVERSAL/
